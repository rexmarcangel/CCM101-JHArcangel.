### Operating System

I used the `cat /etc/os-release` command to identify the operating system of the Linux server. The server is running **Ubuntu 24.04.4 LTS (Noble Numbat)**.

### CPU Information

I used the `lscpu` command to check the CPU information of the Linux server. The server has **1 CPU** with an **x86_64 architecture** and uses an **Intel Xeon E312xx** processor. The server is running with KVM virtualization.

### Memory

I used the `free -h` command to check the memory of the Linux server. The server has **1.9 GiB of total memory**, with around **1.4 GiB available** at the time of checking.

### Disk Space

I used the `df -h` command to check the disk space of the Linux server. The main filesystem has **19 GB of total disk space**, with **5.4 GB used** and around **13 GB available**. The disk is currently using about **30%** of its total capacity.
