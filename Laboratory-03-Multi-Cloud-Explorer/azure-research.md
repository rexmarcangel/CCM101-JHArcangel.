# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides cloud services for computing, storage, databases, networking, security, artificial intelligence, analytics, and application development.

## Global Infrastructure

Azure operates through a global infrastructure consisting of regions and data centers located in different parts of the world. Azure Regions allow organizations to deploy applications closer to their users and help improve availability and performance.

## Cloud Management Console

The Microsoft Azure Portal is a web-based management interface used to create, configure, monitor, and manage Azure resources. Users can manage virtual machines, databases, storage, networking, security, and other cloud services through the portal.

##  Four (4) Core Services

| Service | Description |
|---|---|
| Azure Virtual Machines | Provides virtual machines for running applications and workloads. |
| Azure Blob Storage | Provides scalable object storage for unstructured data. |
| Azure SQL Database | Provides a managed relational database service. |
| Microsoft Entra ID | Provides identity and access management for users and applications. |

## Three (3) Advantages

1. **Microsoft Integration** – Azure integrates well with Microsoft products and technologies.
2. **Scalability** – Azure resources can be scaled based on business requirements.
3. **Enterprise Support** – Azure provides services and tools designed for enterprise organizations.

##  Typical Enterprise Use Cases

Azure is commonly used for enterprise applications, Windows Server workloads, Microsoft 365 integration, databases, application development, data analytics, artificial intelligence, backup, and hybrid cloud environments.
