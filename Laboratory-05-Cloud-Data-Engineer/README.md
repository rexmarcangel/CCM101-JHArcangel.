# Laboratory 05 - Cloud Data Engineer

## Mission Overview

In this laboratory activity, I learned about different types of cloud storage and how object storage can be used for applications that store many files.

I also deployed MinIO using Docker and created a bucket for storing sample files. This activity helped me understand how object storage works and how it can be used in a real cloud environment.

## Objectives

* Learn the differences between Block, File, and Object Storage.
* Deploy MinIO using Docker.
* Access the MinIO Web Console.
* Create a storage bucket.
* Upload a file to the bucket.
* Document the deployment process.
* Practice using Linux and Docker commands.
